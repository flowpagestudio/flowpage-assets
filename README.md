# FlowPage Studio — Assets

מאגר הנכסים הציבוריים של FlowPage Studio.

כאן נשמרים רק נכסים שמותר לפרסם ולהציג: לוגו, אייקונים, רקעים, תמונות דמו ותמונות עבור תרחישי ההדגמה.

## מבנה המאגר

- `00_brand` — לוגו, סימני מותג וחומרי זהות.
- `01_shared` — נכסים חזותיים משותפים לכל התרחישים.
- `02_scenarios` — נכסים ייחודיים לכל תרחיש הדגמה.
- `03_icons` — אייקונים ועזרי ממשק.
- `04_backgrounds` — רקעים, טקסטורות ואלמנטים דקורטיביים.
- `05_source-files` — קובצי מקור שניתן לערוך מחדש.

## כלל פרטיות

לא מעלים לכאן תמונות של לקוחות, מסמכים, פרטים מזהים או כל חומר פרטי. חומרים כאלה ינוהלו בנפרד ב-Google Drive של החשבון העסקי, עם הרשאות מתאימות.
